COMPANION — START HERE

1. Double-click Start Companion.cmd in this folder.
   It starts Companion and opens Today in your browser.
   No reading-group account is needed.

2. Type what you want to get done.
   Try: Add a task to plan my week.
        Save a note: the next meeting needs an agenda.
        Start 25 minutes of focus time.
   You can also edit Tasks and Notes directly.

3. Use the AI selector at the top.
   This development PC has a working Codex / ChatGPT sign-in.
   Settings can connect GPT API, Claude API, a compatible API, or local Ollama.
   Enter API keys only in the app's password field, never in chat.

VOICE
Tap the mic to start; tap again to finish. Cancel stops the current request.
Hands-free is optional and turns off when you switch tabs.
Voice needs the local transcription service. Typing still works without it.

MISSING A TOOL?
Open Build a feature and describe what you need.
The app creates actual source changes, runs checks, and shows the diff.
Ordinary verified features may activate automatically. Protected changes need
review and Activate feature. Build history also offers rollback.
A queued or failed build is not an installed feature.
Reviewed server-worker updates restart and reconnect under the normal launcher.
Changing the host program itself needs its owning host stopped and relaunched;
a browser refresh cannot apply host code. Settings can restart a managed worker.

NEXT TIME
Double-click the same launcher. Your tasks, notes, workflows, and build history
are saved on this computer, outside the source repository.
The default address is http://127.0.0.1:4174/assistant.html.

A fresh checkout needs Node.js 24.15 or newer and an AI connection for chat.
Codex uses its existing CLI sign-in; API providers need your own key and access.
Claude and other API-key accounts have not been live-tested on this PC yet.
Settings → Connect AI tools shows MCP configuration to copy into another client;
it does not change that client’s settings automatically.
